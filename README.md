# 🎵 Surmio Music Player — Official Website

Official website and download portal for **Surmio**, a clean, ad-free music player for Android featuring true background playback, synchronized lyrics, a 10-band equalizer, and offline song downloads.

Live Repository: [https://github.com/aditys4444/surmio-web](https://github.com/aditys4444/surmio-web)

---

## 🌟 Key Features

- **Direct Android APK Download:** Standalone `v1.0` Android APK (~7.7 MB) ready for direct installation.
- **Telegram Community Integration:** Instant join buttons linking to the official channel ([`https://telegram.me/+n5uBAsCDeYUyMjg1`](https://telegram.me/+n5uBAsCDeYUyMjg1)).
- **Mobile-First Responsive Design:** Tested and optimized across all phone screen sizes (360px – 414px), tablets (768px), and desktop viewports.
- **Interactive Screenshot Showcase:** Touch-swipeable carousel with momentum scrolling and instant tab switching.
- **High Performance:** Pure HTML5, modern vanilla CSS, and lightweight JavaScript with zero external frameworks or heavy libraries.

## 🚀 Deployment

This is a static website and can be deployed in seconds to:

### 1. GitHub Pages
1. Go to your repository on GitHub: `https://github.com/aditys4444/surmio-web`
2. Click **Settings** > **Pages**
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site will be live at `https://aditys4444.github.io/surmio-web/`.

### 2. Vercel / Netlify / Cloudflare Pages
1. Import this GitHub repository into Vercel, Netlify, or Cloudflare Pages.
2. Build Settings: None (Static Site). Output directory: `./`
3. Click **Deploy**.
